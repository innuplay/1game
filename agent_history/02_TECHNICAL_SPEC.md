# 📐 Техническая спецификация проекта (Technical Spec)

## 1. Сетка мира и воксели
- **Размер воксельного блока (`BLOCK_SIZE`):** `1.5` стада (компактный уютный масштаб).
- **Сетка привязки:**
  ```lua
  local function snapToGrid(pos, size)
      return Vector3.new(
          math.floor(pos.X / size + 0.5) * size,
          math.floor(pos.Y / size + 0.5) * size,
          math.floor(pos.Z / size + 0.5) * size
      )
  end
  ```
- **Типы блоков мира:**
  - `Grass`: Трава (зелёный цвет, материал `Grass`, дроп `grass_block`)
  - `Wood`: Дерево (коричневый цвет, материал `WoodPlanks`, дроп `wood_block`)
  - `Stone`: Камень (серый цвет, материал `Slate`, дроп `stone_block`)
  - `Dirt`: Земля (тёмно-коричневый цвет, материал `Ground`, дроп `dirt_block`)

## 2. Физика и хитбокс котика ([`PixelCharacter.luau`](../PixelCharacter.luau))
- **Размер `HumanoidRootPart`:** `Vector3.new(1.2, 1.4, 1.2)` (симметричный куб исключает застревания при поворотах).
- **Высота `HipHeight`:** `0.914` стада.
- **Свойства трения:** `PhysicalProperties.new(1.2, 0.85, 0.0, 1.0, 1.0)`.
- **Скорость шага:** `WalkSpeed = 9.5` стад/сек.
- **Коллизии:**
  - `CatTorso.CanCollide = true`, `CanTouch = true`, `CanQuery = true`, `Massless = true`
  - `CatHead.CanCollide = true`, `CanTouch = true`, `CanQuery = true`, `Massless = true`
  - Лапки: `CanCollide = false` (исключает спотыкание о швы между блоками).
- **Формула Foot Ground Snapping:**
  - Расстояние от центра `pawBase` до подошвы носочка: `PAW_BOTTOM_OFFSET = 0.36` стада.
  - Целевая координата подошвы: $Y_{\text{base}} = Y_{\text{ground}} + 0.36$.
  - Локальный сустав: `torso.CFrame:PointToObjectSpace(Vector3.new(worldX, targetY, worldZ))`.
