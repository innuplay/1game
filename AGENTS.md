## 📌 Ключевые правила разработки

1. **Язык общения с пользователем:**
   - ВСЕ ответы пользователю должны быть **строго на русском языке** (100% русский язык, без случайных переходов на английский).

2. **Сохранение в Roblox Studio:**
   - В конце КАЖДОГО ответа ОБЯЗАТЕЛЬНО напоминайте пользователю сохранить плейс комбинацией клавиш **Ctrl + S** в Roblox Studio.

3. **Синхронизация кода с Roblox Studio:**
   - Скрипты проекта редактируются на диске в `c:\Users\Nine\Desktop\1game\`:
     - `VoxelClient.luau` (клиентская логика, HUD, инвентарь, ввод, выделение блоков)
     - `VoxelServer.luau` (серверная воксельная генерация, блоки, инвентарь игроков, сетевые события)
     - `PixelCharacter.luau` (процедурная модель котика, процедурная анимация, физика, примагничивание лапок)
   - Синхронизация кода в DataModel Студии осуществляется через локальный фоновый HTTP-сервер (`http://127.0.0.1:8088/`) скриптом Luau в Edit DataModel.
   - Перед передачей хода пользователю Studio ВСЕГДА должна быть возвращена в режим редактирования (`Edit mode`), а не оставаться в `Play mode`.

4. **История действий агентов:**
   - После КАЖДОЙ завершенной задачи агент ОБЯЗАН вносить запись в журнал [`agent_history/01_DEVELOPMENT_LOG.md`](./agent_history/01_DEVELOPMENT_LOG.md) с описанием:
     - Запрос пользователя
     - Причина проблемы / суть задачи
     - Внесенные изменения
     - Результаты тестов
   - Делать Git-коммит с понятным описанием изменений.
